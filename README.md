# 中文歌词多音字处理系统

基于 React (Vite) + Node.js (Express) 的中文歌词多音字检测与替换系统：自动识别多音字、推荐正确读音，并可将多音字替换为同音非多音字。

## 项目结构

- `frontend/`：React + Vite + Ant Design
- `backend/`：Node.js + Express + TypeScript（基于 `pinyin-pro`）

## 启动步骤

环境要求：Node.js v16+

```bash
# 1. 启动后端（端口 3001）
cd backend
npm install
npm run dev

# 2. 启动前端（端口 5173）
cd frontend
npm install
npm run dev
```

浏览器访问 `http://localhost:5173/` 即可使用。

## 功能说明

### 1. 单个运行
- 选择「检测全部」或「仅检测指定多音字」（可上传 TXT 提取汉字）。
- 输入歌词 → 检测 → 多音字高亮显示。
- 在统计表中勾选并填写替换字 → 应用替换 → 复制或导出 TXT。

### 2. 批量运行
- 上传 CSV / XLSX / XLS（歌词放在第一列，自动识别中文编码）。
- 系统逐条检测并跨条目聚合统计多音字读音。
- 统一配置替换规则后批量应用并导出。

### 3. 多音字库配置
- 输入或上传汉字 → 解析为各读音。
- 为每个读音设置「替换字」或勾选「忽略」。
- 配置作为全局规则，自动作用于单个/批量运行。

## 注意事项

- 必须先启动后端，否则前端检测请求会失败。
- 替换字应为单个汉字，与原字长度一致。
- CSV/Excel 文件需将歌词放在第一个 Sheet 的第一列。
- 若 5173 端口被占用，Vite 会自动切换至 5174 等其他端口，以终端实际输出为准。
